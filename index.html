⚙️ Step-by-Step Installation Guide Easy 2-Step Run

⚠️ IMPORTANT NOTICE FOR FIRST-TIME RUNS:
1. Initial Load: The first time you click "AI Background Cutting", the tool automatically maps and downloads necessary weights locally. This may take 1-2 minutes depending on your PC. Subsequent runs are near-instant.
2. Security Warnings: When launching main.exe, Windows Defender might prompt a warning. Click "More Info" -> "Run Anyway".

1️⃣ Step 1: Place GIMP Plug-in Folders (First Time Only)

Move the following two folders from the downloaded pack into your GIMP plugins directory:

  • Folders to copy: ai_lipsync_engine and remote_listener
  • Windows Target Path:
    C:\Users\<Your_Username>\AppData\Roaming\GIMP\3.0\plug-ins\

*Note: Restart GIMP completely after moving the folders.

2️⃣ Step 2: Folder Structure Reference

Keep the downloaded folder layout intact without shifting core files:

GIMP AI ASSISTANT1.3/
├─AI_Input          <-- Place raw images here
├─AI_Output         <-- Processed files save here automatically
├─ main.exe         <-- Double-click to boot the local AI server
├─ models/
├─ plug-ins/
│   ├─ ai_lipsync_engine
│   └─ remote_listener
├─ audio/           <-- Store lip-sync voice clips here
└─ internal/

3️⃣ Step 3: Daily Workflow & Usage

  1. Launch GIMP. Every session, trigger the native server: Go to GIMP Menu -> Filters -> Development -> Script-Fu -> [Start Server]. Confirm Port is 10008 and click OK.
  2. Double-click and launch main.exe.
  3. Drop your images into the AI_Input folder.
  4. Interact using the local browser dashboard interface to activate cutting, erasing, or automated batch workflows!
